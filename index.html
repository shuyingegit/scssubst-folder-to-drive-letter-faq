Map a local folder to a Windows drive letter without copying

Short answer: map the folder to a drive letter so deep paths become a short letter—no file copy.

ScsSubst does this on Windows. It is not a WebDAV/NAS mount (that is ScsDrive).

  • Product: https://subst.scsoi.com/
  • Download / trial: https://subst.scsoi.com/#download
  • Pricing: https://subst.scsoi.com/#pricing

Useful for shorter paths and isolating AI/agent workspaces.
